# Česko v číslech (Czechia by numbers)

Česko v číslech shows the most important data about Czechia in a simple, easy-to-reuse form. Each article covers one topic with 5–10 key charts and a short text that gives them context. The project takes inspiration from [UK by Numbers](https://ukbynumbers.org/) and [Our World in Data](https://ourworldindata.org/), and it is a spare-time project without funding.

## Topics
- **Obyvatelstvo**: Počet obyvatel a růst, Stárnutí a porodnost
- **Společnost**: Zdraví a naděje dožití, Chudoba a nerovnost; coming: Vzdělávání, Bydlení, Kriminalita
- **Ekonomika**: HDP a ekonomický růst, Zaměstnanost a mzdy
- **Energetika a životní prostředí**: coming: Energetika, Emise skleníkových plynů, Životní prostředí
- **Veřejné finance**: Veřejné rozpočty, Daňový systém; coming: Důchody, Zdravotnický systém

## Data
Official sources come first: mostly ČSÚ and the open data of Czech state institutions; for international comparisons Eurostat, OECD, the World Bank, the IMF and the WHO. Long time series sometimes join two sources (e.g. Eurostat before 2000, ČSÚ after). Every chart names its sources, links to the dataset and offers its data as CSV.
